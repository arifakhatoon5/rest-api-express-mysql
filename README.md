
REST API Using Express.js and MySQL

Project Description

This project is a REST API built using Node.js, Express.js, and MySQL.

Features

- Connects to a MySQL database.
- Retrieves all users using GET.
- Inserts new users using POST.

Requirements

- Node.js
- MySQL
- npm

Installation

1. Install the required packages using "npm install".
2. Create the database by running the "database.sql" file in MySQL.
3. Update the database credentials in "server.js".

Run the Project

Run the following command:

"npm start"

The server runs on port 3000.

API Endpoints

- GET "/" : Check server status.
- GET "/users" : Retrieve all users.
- POST "/users" : Insert a new user.

Technologies Used

- Node.js
- Express.js
- MySQL
